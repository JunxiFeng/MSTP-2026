# Command Line Cheatsheet

**REFERENCE**

Use commands to answer project questions: `pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `head`, `tail`, `less`, `wc`, `grep`, `find`, `sort`, `uniq`, and `cut`.

Paths: `.` means here, `..` means one folder up, absolute paths start from the filesystem root, and relative paths start from your current folder.
