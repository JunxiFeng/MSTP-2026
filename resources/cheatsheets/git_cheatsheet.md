# Git Cheatsheet

**REFERENCE**

- `git clone URL` copies a repository.
- `git status` shows changed files.
- `git diff` shows line-level changes.
- `git add FILE` stages a file.
- `git commit -m "message"` records a local commit.
- `git log --oneline` shows history.
- `git pull` fetches and integrates remote changes.
- `git push` sends local commits to a remote.

Git is not GitHub. Git tracks versions; GitHub hosts repositories.
